# Archivos Swiss Ephemeris

Estos archivos binarios oficiales se obtuvieron del repositorio público de
Astrodienst/Swiss Ephemeris:

- `sepl_18.se1`: planetas, 1800–2399.
- `semo_18.se1`: Luna, 1800–2399.
- `seas_18.se1`: asteroides principales, 1800–2399.

Fuente: <https://github.com/aloistr/swisseph/tree/master/ephe>

Swiss Ephemeris se distribuye bajo su licencia dual (AGPL o licencia
profesional). Este proyecto se distribuye bajo AGPL-3.0-or-later; consulta el
archivo `LICENSE` en la raíz del repositorio.
